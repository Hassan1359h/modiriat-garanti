# نسخه 3 مدیریت فروشگاه و گارانتی

اصلاحات:
- هیچ `n` یا `\\n` یا شماره ردیف کنار کد ذخیره یا نمایش داده نمی‌شود.
- کدها پاک‌سازی می‌شوند و کدهای عددی صعودی مرتب می‌شوند.
- کپی، واتساپ، پیامک و CSV از خط جدید واقعی استفاده می‌کنند.
- افراد و فروشگاه‌ها در بخش پایین صفحه نیز قابل مشاهده و جستجو هستند.
- امکانات قبلی شامل ثبت، انتخاب فروشگاه، ویرایش، حذف، جستجو، CSV، پشتیبان، بازیابی، ذخیره محلی و PWA حفظ شده‌اند.

فایل‌های این ZIP را در Repository مربوط به GitHub Pages جایگزین کنید.
