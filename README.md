# مدیریت گارانتی — GitHub Pages

این پروژه یک PWA کاملاً محلی است و اطلاعات را در `localStorage` همان مرورگر/گوشی نگه می‌دارد.

## نصب روی GitHub Pages
1. محتوای این پوشه را در همان Repository فعلی GitHub Pages قرار دهید و Commit کنید.
2. در GitHub از Settings → Pages مطمئن شوید Source روی branch/folder صحیح است.
3. لینک GitHub Pages را با Chrome/Edge یا Safari روی گوشی باز کنید و از گزینه **Add to Home Screen / افزودن به صفحه اصلی** نصب کنید.

## نکته مهم واتساپ
لینک گروه واتساپ داخل دکمه واتساپ تنظیم شده است. به دلیل محدودیت امنیتی WhatsApp و مرورگر، یک وب‌سایت نمی‌تواند بدون اجازه کاربر مستقیماً داخل یک گروه پیام ارسال کند. دکمه، متن کامل گارانتی را در کلیپ‌بورد کپی می‌کند و سپس گروه را باز می‌کند تا متن را در گروه Paste و ارسال کنید.

## کد گارانتی
کدها شماره‌گذاری نمی‌شوند و دقیقاً همان متن واردشده ذخیره/نمایش داده می‌شود؛ مثلاً `78905` به `78905.10` تبدیل نمی‌شود.
