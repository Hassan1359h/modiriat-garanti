# مدیریت فروشگاه و گارانتی — نسخه اصلاح‌شده

این نسخه برای GitHub Pages آماده است.

## اصلاحات مهم
- کدهای گارانتی همیشه عددی و صعودی مرتب می‌شوند.
- کدهای تکراری حذف می‌شوند.
- کدهایی مثل `78601`, `78600`, `78603` به `78600` تا `78603` تبدیل می‌شوند.
- در متن کپی/واتساپ/پیامک، خط جدید واقعی استفاده می‌شود و عبارت `\n` به‌صورت متن نمایش داده نمی‌شود.
- شماره‌های ۱ تا ۳۰ کنار کدها تولید یا نمایش داده نمی‌شوند.
- اطلاعات فروشگاه جداگانه ذخیره می‌شود و برای ثبت‌های بعدی قابل انتخاب است.
- ویرایش، حذف، جستجو، CSV، پشتیبان‌گیری/بازیابی و ذخیره محلی فعال است.
- قابلیت نصب به‌صورت PWA روی گوشی فراهم شده است.

## نصب روی GitHub Pages
محتویات این ZIP را در همان Repository قبلی جایگزین کنید و مطمئن شوید `index.html` در مسیر اصلی Pages قرار دارد.
