نسخه نهایی V5 مدیریت گارانتی راسان
- مشکل \n در متن کپی اصلاح شده و کدها با newline واقعی جدا می‌شوند.
- کدها تک‌ستونه و مرتب هستند.
- n و شماره‌گذاری و علائم اضافی از کدها پاک می‌شود.
- فروشگاه/فرد بدون کد قابل ذخیره است.
- افراد و فروشگاه‌ها در پایین نمایش داده می‌شوند.
- Service Worker نسخه‌های قدیمی را حذف می‌کند تا کش قدیمی مانع اجرای نسخه جدید نشود.
- اطلاعات نسخه‌های قبلی در localStorage در صورت وجود مهاجرت داده می‌شود.

نصب:
1. فایل‌های داخل ZIP را در ریشه Repository مربوط به GitHub Pages جایگزین کنید.
2. اگر نسخه قبلی روی گوشی باز است، یک‌بار صفحه را کامل Reload کنید.
3. برای PWA از مرورگر گزینه Add to Home Screen را بزنید.

واتساپ:
دکمه «ارسال واتساپ / گروه» از Share گوشی استفاده می‌کند تا گروه را انتخاب کنید. وب‌سایت نمی‌تواند حساب فرستنده را به‌صورت اجباری تعیین کند.
