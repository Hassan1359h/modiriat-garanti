نسخه V8 - رفع مشکل نمایش لوگو در GitHub Pages

1) تمام فایل‌های داخل این ZIP را در همان پوشه GitHub Pages پروژه قبلی جایگزین کنید.
2) حتما پوشه icons هم آپلود شود.
3) Commit / Push کنید.
4) اگر اپ قبلی روی گوشی نصب است، میانبر قبلی را حذف و دوباره Add to Home Screen کنید.
5) یک بار صفحه را با مرورگر باز کنید و Refresh کامل انجام دهید.

در این نسخه:
- مسیر آیکون‌ها برای GitHub Pages زیرشاخه‌ای اصلاح شده.
- favicon و apple-touch-icon اضافه شده.
- manifest دارای start_url و scope صحیح است.
- کش Service Worker نسخه جدید دارد تا آیکون قدیمی گیر نکند.
- لوگو داخل سربرگ خود برنامه نیز نمایش داده می‌شود.

نکته: آیکون موجود در این بسته همان آیکون RASSAN طراحی‌شده برای نسخه قبلی است؛
اگر فایل لوگوی رسمی و دقیق راسان را دارید، آن را بفرستید تا همان فایل را به آیکون 192 و 512 تبدیل کنم.
