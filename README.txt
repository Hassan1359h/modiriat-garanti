نسخه V12 مدیریت گارانتی راسان

نکته مهم: در این نسخه فایل‌های آیکن عمداً در ریشه مخزن قرار گرفته‌اند، چون در ساختار فعلی GitHub شما فایل‌های PNG در ریشه دیده می‌شوند و پوشه icons وجود ندارد.

برای نصب: app-v12.html را باز کنید و سپس از منوی مرورگر «افزودن به صفحه اصلی / نصب برنامه» را بزنید. اگر نسخه قدیمی نصب است، ابتدا میانبر/برنامه قدیمی را حذف و سپس V12 را نصب کنید.
