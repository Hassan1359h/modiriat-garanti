نسخه نهایی مدیریت گارانتی راسان
1) محتویات این پوشه را در GitHub Pages جایگزین فایل‌های قبلی کنید.
2) برنامه روی مرورگر با localStorage کار می‌کند.
3) برای نصب روی گوشی، صفحه GitHub Pages را با Chrome/مرورگر سازگار باز کنید و گزینه Add to Home Screen را بزنید.
4) ارسال به گروه واتساپ: دکمه «ارسال به واتساپ / گروه» از Share گوشی استفاده می‌کند تا شما گروه را انتخاب کنید.
5) وب‌سایت نمی‌تواند حساب فرستنده واتساپ را به‌صورت اجباری تعیین کند؛ واتساپ از حسابی که روی گوشی وارد شده استفاده می‌کند.
