نسخه نهایی V10 — رفع قطعی مشکل آیکون و کش

این نسخه برای جایگزینی نهایی ساخته شده است.

مراحل نصب:
1) برنامه فعلی «گارانتی راسان» را از صفحه اصلی گوشی حذف کنید.
2) تمام فایل‌های داخل این ZIP را در ریشه GitHub Pages پروژه جایگزین کنید.
3) حتما پوشه icons و فایل sw-v10.js و app-v10.html هم آپلود شوند.
4) Commit / Push کنید و صبر کنید GitHub Pages به‌روزرسانی شود.
5) سایت را با Chrome باز کنید.
6) دوباره Add to Home screen / Install app را بزنید.

نکته:
- اطلاعات ذخیره‌شده برنامه در localStorage با تغییر نسخه پاک نمی‌شود.
- V10 از نام فایل‌های کاملاً جدید برای آیکون و Service Worker استفاده می‌کند تا V7/V8/V9 از کش برنگردند.
- لوگوی RASSAN از فایل لوگوی ارائه‌شده استفاده شده و با اندازه مناسب برای آیکون‌های Android آماده شده است.
- امکانات برنامه تغییر داده نشده‌اند.
